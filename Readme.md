Birthday Card Project
This is a small interactive birthday website I built while learning web development on Scrimba.

What I Learned & Concepts Used
HTML Structure: Using divs, headings, and images to organize content.

CSS Flexbox: Aligning cards in rows and centering text.

Hover Effects: Using :hover to switch background images when the user hovers over a gift.

Background Images: Setting up images with background-image, background-size, and background-position.

Audio Tag: Adding music with the HTML <audio> element and starting playback at a specific time using #t=7.

Resource Preloading: Using <link rel="preload"> in the head tag to help media load faster.

Basic Styling: Adding Google Fonts, custom text colors, and simple shadows.
